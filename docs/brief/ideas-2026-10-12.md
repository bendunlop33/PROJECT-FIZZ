## Ideas (design deep-dive → proposal for Ben)
3. **Workout Split** (rename of Push/Pull/Legs): categories chest / shoulders / legs / push (+ back/pull etc.); a session mixing chest and shoulders counts as Push. Workout Split is the **default** view; body parts become **Muscle group**.
4. **Muscle groups:** no forearms; traps, lats (and other back sub-groups) instead of just "back"; chest split into upper / lower (or the right sub-groups).
5. **Settings:** an on/off option to show how long the current set is taking (after rest). Default off.
6. **Progress structure:** a selector for Activity Overview / Strength Overview / Calendar. No "All": a **dropdown of exercises**, immediately showing **line graphs over time** of each measurement, both the logged value and a **trailing average over N sessions** (Ben picks N). Measures: estimated 1RM, top set weight, frequency of top sets/weights, total weight lifted per session.
7. **Profile › Training personal criteria:** age, gender, training goals, training frequency goal (flexible week to week), weight, height.
8. **Workout selector: two modes, coach-driven or self-driven**, each with a choice of workout split.
   - **Self-driven:** recommendations by split, but Ben chooses each exercise; only a default set structure is pre-filled (not tailored from history).
   - **Coach-driven:** goals in Profile (strength / muscle / combination) guide the build. Default session 45 min, adjustable ±5, ±10, ±15 min. Recommends the **main heavy lift** with an option to change it (chest: flat barbell bench, incline DB, incline barbell; shoulders: DB shoulder press or other; legs: squat or leg press; back: rows vs deadlift, pull-ups vs lat pulldown), the rest of the session built around it; sets and rest recommended.

## Ben's decisions (12 Oct, later)
- **Push: yes** (a session mixing chest and shoulders is Push).
- **Split categories include their arm muscles:** **Chest** includes triceps; **Shoulders** includes triceps too; **Back** includes biceps (Back & biceps). Legs as is.
- **Coach goals are a Profile coach setting, not asked each workout:** shown the first time Ben uses a coach-driven workout, then a **check-in every X weeks (default 6, adjustable)** asks whether goals still hold. Coach-driven builds read the saved goals.
