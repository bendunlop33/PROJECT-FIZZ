Workout table: whole session, anchored on the current set, one Log

Build-ready, 12 Oct 2026. Spec: docs/design/active-workout.md §2A, with Ben's decisions of 11 Oct applied. The screen opens anchored on the current set. Finished sets and exercises sit above the viewport, and a ↑ N done chip in the top bar says they're there. After each Log the list auto-advances. Done rows are bright with a green tick (actual), and pending rows are dim with an open ring (target). Only the current row opens. The bottom bar is Chat + Log, and Pause and Finish are in ⋯. Tapping a row that isn't current selects it and never logs. Build 108's single card stays as ⋯ → Focus view. Frames use realistic Push numbers. This is a mockup only: it hasn't been rendered on a device.

Ben's decisions (11 Oct 2026)

1. Declutter by default. Opens anchored on the current set, with done sets and exercises above the viewport, a ↑ N done chip, auto-advance after each Log (Reduce Motion: no animation, same position), and restore landing on the same set.
2. Focus stays as an option in ⋯ (Focus view).
3. Bottom bar = Chat + Log. Pause and Finish are in ⋯, and Finish takes the Log slot after the last set.
4. A non-current row's tick selects it and moves Log to it. It never logs.
